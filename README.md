# Mi Portfolio de Desarrollo e Innovación Tecnológica 

*Desarrollo de software · Automatización · Inteligencia Artificial · Visión Artificial · IoT · Sistemas industriales*

## Sobre mi trabajo
Mi trabajo combina desarrollo de software, electrónica, automatización, inteligencia artificial y sistemas de control para transformar problemas concretos en soluciones tecnológicas funcionales.
***No se trata solamente de programar:*** los proyectos parten de una necesidad real, analizan el problema, integran hardware y software cuando es necesario y buscan llegar a una solución que pueda probarse, utilizarse y evolucionar.

A continuación presento algunos de los desarrollos que mejor representan estas capacidades.

### 💧 Planta de tratamiento de agua por método electroquímico
Tratamiento y monitoreo automatizado de agua mediante procesos electroquímicos.

🔗 [Repositorio del proyecto](https://github.com/ETI-PATAGONIA-AR/Planta-de-treatamientos-de-agua-por-m-todo-electroqu-mico-PTEC-)
▶️ [Video del proyecto](https://www.youtube.com/watch?v=AnWnhU66LvI)

***¿Qué demuestra?***
Este desarrollo integra electrónica, sensores, adquisición de datos, control automático y software, aplicados a un proceso físico real.

### 👁️ VIA — Visión Artificial aplicada a HSE
Un sistema de visión artificial orientado a Seguridad, Higiene y Medio Ambiente.

🔗 [Repositorio VIA](https://github.com/ETI-PATAGONIA-AR/VIA-Vision-Artificial-aplicada-a-HSE)
▶️ [Video de VIA](https://www.youtube.com/watch?v=7pjkqY5xVAE)

***¿Qué demuestra?***
VIA utiliza visión artificial e inteligencia artificial para analizar imágenes provenientes de cámaras y detectar situaciones relacionadas con seguridad.
El objetivo no es solamente "detectar objetos", sino convertir la información obtenida de una cámara en información útil para un proceso de HSE.
Entre sus aplicaciones se encuentra la detección de personas y el análisis del uso de elementos de protección personal.

***Capacidades involucradas:***
- *Computer Vision.*
- *Inteligencia Artificial.*
- *Visión Artificial.*
- *Modelos YOLO.*
- *Segmentación.*
- *Open Vocabulary Detection.*
- *Clasificación mediante modelos multimodales.*
- *Tracking de personas.*
- *Procesamiento de video.*
- *Automatización de registros.*
- *Aplicaciones de IA orientadas a seguridad industrial.*

### 🌊 Visión Artificial + Nanoburbujas
Aplicación de Inteligencia Artificial y tecnologías de nanoburbujas para procesos de mitigación de contaminación bentónica en acuicultura.

🔗 [Repositorio del proyecto](https://github.com/ETI-PATAGONIA-AR/Mitigacion-de-la-Contaminacion-Bentonica-en-Acuicultura-con-IA-y-Nanoburbujas)

***¿Qué demuestra?***
Este proyecto combina dos áreas tecnológicas diferentes: *Visión Artificial + tratamiento mediante nanoburbujas.*
La visión artificial permite obtener información del entorno y evaluar el proceso, mientras que la generación e inyección de nanoburbujas constituye la parte física de intervención.
Es un ejemplo de cómo integrar software inteligente con procesos físicos y ambientales.

***Capacidades involucradas:***
- *Inteligencia Artificial.*
- *Computer Vision.*
- *Procesamiento de imágenes.*
- *Automatización.*
- *Electrónica.*
- *Control de procesos.*
- *Tecnologías ambientales.*
- *Integración de sistemas.*
- *Investigación y desarrollo tecnológico.*

### 🔧 Una característica común
Aunque los proyectos pertenecen a áreas muy diferentes, todos parten de una misma forma de trabajo:

*Problema real → análisis → diseño → desarrollo → integración → prueba → solución funcional*

La tecnología no se utiliza como un fin en sí mismo, sino como una herramienta para resolver problemas concretos.
Esto permite trabajar en proyectos donde software, electrónica, inteligencia artificial, automatización y procesos físicos tienen que convivir dentro de una misma solución.
